1)    После успешной авторизации приложение отображает основной экран с картой доступной территории обслуживания (см. п. [[3.6.8. Зоны каршеринга]]). Пользователю предлагается поделиться геолокацией.

a.     Пользователь делится геолокацией – система определяет его местоположение и показывает автомобили поблизости, если таковые есть.
b.    Пользователь отклоняет предложение поделиться геолокацией – система показывает общую карту со всеми автомобилями.

2)    Система получает информацию о доступных для бронирования автомобилей, после чего отображает их на карте в виде условных обозначений.

3)    Пользователь перемещает и масштабирует карту для поиска подходящего автомобиля.

4)    При выборе автомобиля приложение открывает его карточку. Карточка содержит доступную пользователю информацию, включая: марку и модель, регистрационный номер, фотографию, действующий тариф, уровень топлива, информацию о страховке.
