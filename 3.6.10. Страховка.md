В разделе пользователь может ознакомиться с доступной ему страховкой, а также выбрать иную.

| Страховка  | Фичи                            |
| ---------- | ------------------------------- |
| Базовая    | Полный штраф за ДТП             |
| Каско      | Штраф за ДТП до 65 тыс. руб.    |
| Суперкаско | Нет штрафов за ДТП.             |
| Турбокаско | 0 руб. при ДТП + быстрый старт. |
