1) Ночная парковка
Время бесплатной ночной парковки вне зоны каршеринга 23:00-7:00.

2) Вопрос-ответ
Чат с поддержкой, суженый до основных категорий, вопросы по которым возникают, а также ответы на них.

3) Договор
Пользователь может открыть полный текст договора на: согласие на получение рекламных и маркетинговых рассылок, договор аренды, пользовательское соглашение, согласие на обработку персональных данных.

4) Системные уведомления
Включение пуш-уведомлений. Тумблер, по умолчанию – включен.

5) Сохранение фотографий осмотра
Функция сохраняет снимки в галерею смартфона. Тумблер, по умолчанию – включён.

6) Mos ID
Пользователю предлагается прикрепить аккаунт mos.ru. Если аккаунт привязан - показывается соответствующая запись.

7) Выход из аккаунта
Пользователь может выйти из аккаунта. При нажатии кнопки приложение запрашивает подтверждение действия.

8) Удаление аккаунта
Пользователь может удалить аккаунт. При нажатии кнопки приложение запрашивает подтверждение действия. появляется сообщение о необратимости действия.
