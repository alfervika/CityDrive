1)    При первом запуске приложения пользователю предоставляется возможность создать новую учётную запись.

2)    Пользователь вводит в предложенное поле номер телефона для регистрации, после чего на указанный номер высылается единоразовый цифровой код подтверждения.

a.     Если номер телефона уже связан с существующей учётной записью, приложение предлагает перейти к авторизации.

3)   Пользователь вводит код в окно для ввода кода, после чего система проверяет корректность введённого кода.

a.     Код введен верно – пользователю доступен следующий этап регистрации.
b.    Код введен неверно / по истечении времени – система сообщает об ошибке и предоставляет возможность повторить операцию.

4)    Далее пользователь переходит на следующий этап регистрации, где вводит свою почту и принимает условия пользования сервисом.

| Поле                         | Значение                                                                                                                                                                                                          |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Поле для ввода почты         | Текстовое поле (по умолчанию – пустое)                                                                                                                                                                            |
| Условия пользования сервисом | Условия договора (чекбокс, по умолчанию - не выбран)<br><br>Согласие на обработку персональных данных (чекбокс, по умолчанию - не выбран)<br><br>Подтверждение стажа вождения (чекбокс, по умолчанию - не выбран) |

5)    При успешном подтверждении номера телефона пользователь переходит к заполнению персональных данных. Приложение предоставляет возможность загрузки фотографий или сканов необходимых документов.

| Документ                   | Приложение                                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------------------------- |
| Паспорт                    | Разворот с фотографией<br><br>Разворот с регистрацией<br><br>Селфи с паспортом (разворот с фотографией) |
| Водительское удостоверение | Обе стороны                                                                                             |

6)    Пользователь отправляет заполненные данные на проверку. Приложение отображает текущий статус проверки.

a.     Успешная проверка – пользователь получает уведомление об успешном создании учетной записи.
b.    Проверка не пройдена – пользователь получает уведомление об отклонении проверки, а также комментарии о том, почему проверка не пройдена и как это исправить. Пользователь возвращается в начало пункта.

7)    Пользователь привязывает банковскую карту (см. п. [[3.6.2. Способы оплаты]]).

8)    Пользователь получает доступ к основному интерфейсу приложения (см. п. [[3.2. Поиск и выбор автомобиля]]).
